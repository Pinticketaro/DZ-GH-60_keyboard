# DZ-GH-60_keyboard

DZ60 V2（はんだ付け版）PCBを使った60%キーボード。旧デザイン（2025年の積層ケース案）を踏襲し、トッププレート（アクリル1.5mm）＋補強板（アクリル2mm）／枠（PLA・3Dプリント、Ender-3 Proで2分割）／ボトムプレート（アクリル・CO2レーザー）を重ねてM3ネジで共締めする。PCBはネジ止めせず、スイッチの爪でトッププレートに固定し、柔らかい台座で下から支える。外形315×126mm、角はApple風の角丸。

## フォルダ構成

| フォルダ | 中身 |
|---|---|
| `layout/` | 配列データ（KLE JSON） |
| `tools/` | 図面生成スクリプト（`gen_case.py`：プレート・枠・底板、`corner_compare.py`：角丸の比較、`overlay.py`：重ね合わせ確認、`section.py`：断面図、`build3d.py`：3Dモデル（STL）、`render_preview.py`／`variants.py`：外観プレビュー、`analysis.py`：たわみ・重さ・傾きの見積もり）。`pip install -r tools/requirements.txt` |
| `plate/` | トッププレートの図面（SVG / DXF） |
| `case/` | 枠・ボトムプレート・足・フォーム型紙の図面、角丸テスト片、印刷用STL（`stl/`）、Fusion 360から書き出したSTEP |
| `measurements/` | DZ60の実測値 |
| `photos/` | テストカット・試し刷り・組み立ての写真 |
| `docs/` | 決定事項、基準寸法、Tips、事例とアイデア・進行方式、旧プロジェクトの調査、改善案、図（`img/`） |
| `LOG.md` | 製作ログ |

## 進め方

1. 入力をそろえる：KLE JSON（済）、スケッチ、実測値
2. プレート：図面生成 → テストカット → カーフ確定 → 本番
3. ケース：土台モデル → USB部と角の試し刷り → 2分割で本番
4. 組み立て：スタビ取付 → スイッチ＋プレート仮組み → はんだ付け → ケース固定 → 動作確認

詳しくは [docs/決定事項.md](docs/決定事項.md)、マイルストーンは [docs/事例とアイデア.md](docs/事例とアイデア.md)。

## ルール

- **単位はmm、原点はPCB外形の左上**（X右・Y下）。全ソフトのデータをこれに合わせる。
- **ファイル名に版番号と主要パラメータを入れる**：例 `plate_v03_kerf0.15.dxf`
- **コミットメッセージを製作ログにする**：何を変えて、実物でどうだったかを書く。
  - 例：`plate v03: カーフ0.15で切断 → スイッチがややゆるい。次は0.18`
- **実物を作ったらタグを付ける**：例 `test-cut-1`、`case-proto-1`
- **.f3d / .blend は入れない**：Fusion 360は独自の版管理があるので、書き出したSTEPだけを入れる。
- **.gcode は入れない**：STLとスライサー設定から作り直せるため。
