# 自作キーボード（DZ60）決定事項

最終更新：2026-10-14

## 資材
| 項目 | 決定 | 備考 |
|---|---|---|
| PCB | DZ60 V2（はんだ付け版） | 配列はPCB上の対応レイアウトから選ぶ |
| 配列 | ISO系カスタム（KLE：`layout/layout_kle.json`） | 分割Backspace、ISO Enter、左Shift 1u＋1u、右Shift 1u×3、下段 1.25u×3＋6.25u＋1u×6。DZ60で実装済みの配列 |
| プレート | CO2レーザーで自作、厚み1.5mm | 素材は未決（候補：POM／アクリル／薄合板） |
| ケース | PLA、Ender-3で2分割印刷 | 分割線は土台モデルを見てから決める |
| 接合 | ダボ＋M2ネジ＋熱圧入インサート（推奨案） | 未確定 |
| スタビ | PCBマウント・ネジ止め式 | はんだ付け前に取り付ける |
| 版管理 | GitHubリポジトリ | テキスト形式（SVG/DXF/JSON/コード）は差分管理、STEP/STLは版の記録 |

## 道具の分担
- Claude：基準寸法・プレート図面（mm単位SVG/DXF）・ケース土台モデル（STEP）・寸法チェック・部品表
- Fusion 360：ケースの最終造形（本人）→ STEPで返して寸法チェック
- Inkscape：プレート図面の確認とレーザーへの出力（本人）
- Blender：完成イメージのレンダリング（任意）

## 進め方
1. 入力をそろえる：KLE JSON（済）、スケッチ、実測値
2. プレート：図面生成 → テストカット（スイッチ穴1＋スタビ1組）→ カーフ確定 → 本番
3. ケース：土台モデル → USB部と角の試し刷り → 2分割で本番
4. 組み立て：スタビ取付 → スイッチ＋プレート仮組み → はんだ付け → ケース固定 → 動作確認

## 未決事項
- プレート素材
- ケースの分割線（直線／階段状）
- Ender-3の機種、CO2レーザーの加工エリア
- DZ60実測値（USB-C位置・高さ、裏面部品高さ、ネジ穴の有無）
