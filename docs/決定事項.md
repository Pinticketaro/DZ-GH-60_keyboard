# 自作キーボード（DZ60）決定事項

最終更新：2026-10-15

## 基本方針
**旧デザイン（2025-03-05の積層ケース案）を基本的に踏襲する。** 旧データの中身は [旧プロジェクト.md](旧プロジェクト.md)。

## 資材
| 項目 | 決定 | 備考 |
|---|---|---|
| PCB | DZ60 V2（はんだ付け版） | 配列はPCB上の対応レイアウトから選ぶ |
| 配列 | 旧配列どおり（KLE：`layout/layout_kle.json`） | **2u Backspace**、ISO Enter、Caps段1u×12、4段目1u×15（左右Shiftとも1u分割）、下段 1.25u×3＋6.25u＋1u×5。計65キー（2026-10-15変更：分割BS→2u） |
| ケース方式 | **積層（サンドイッチ）・混成**：トッププレート（アクリル1.5）／補強板（アクリル2）／枠（PLA・3Dプリント）／ボトムプレート（アクリル） | 4層をM3ネジ8本で共締め。**接着しない** |
| PCBの固定 | **ネジ止めしない**。スイッチの爪がトッププレートの裏に掛かって上方向、肩がプレート上面に乗って下方向を止める。ボトムプレート側の柔らかい台座で下から軽く支える（ダンパー） | 2026-10-15決定。台座の素材・位置は未決（PCB裏の部品を避ける） |
| 外形 | **315×126mm**（旧デザイン） | 枠の幅14mm → 枠の内側287×98mm（PCB 285×94.6の周囲に約1mm） |
| 角 | **Apple風の角丸**（曲率が連続する角）。枠の内側の角も同じ方式で丸める（R4.5） | 外側の半径とスムージングは未決。比較図 `docs/img/corner_compare.png`、テスト片 `case/corner_test_A4.svg` |
| トッププレート | **アクリル1.5mm**、CO2レーザー。スイッチ・スタビ穴は旧swillkb出力（Cherryスタビ） | MXの爪が掛かる厚さ（1.6mm以下）。1.5mmアクリルはスタビ周りが割れやすいのでキャスト材を推奨 |
| 補強板 | **アクリル2mm（仮）**、CO2レーザー。トッププレートの下に重ね、枠との間に挟んで共締め | 剛性確保のため（2026-10-15決定、3mm案は爪が掛からず不可）。穴はトッププレートより片側0.8mm大きく（15.6角）爪の逃げを確保。重ねるだけでトッププレート単体の約3.4倍の剛性。3mmにすると約9倍だがPCBとのすき間0.5mm |
| 枠 | PLA、Ender-3 Pro、左右2分割（中央 X=142.5） | 厚さ8.1mm（仮）＝補強板〜PCB 1.5＋PCB 1.6＋台座5。自動計算 |
| ボトムプレート | **アクリル**、CO2レーザー、3mm（仮） | 台座の土台になる |
| ネジ | M3×8本（旧デザインの位置。角の4本は角丸に合わせて内側へ） | ネジ長さ・ナット／インサートは未決 |
| 装飾 | 矢絣模様は入れない | 2026-10-15決定 |
| スタビ | PCBマウント・ネジ止め式 | はんだ付け前に取り付ける |
| 版管理 | GitHubリポジトリ | テキスト形式（SVG/DXF/JSON/コード）は差分管理、STEP/STLは版の記録 |

## 道具の分担
- Claude：基準寸法・図面生成（`tools/gen_case.py`）・枠の土台モデル（STEP）・寸法チェック・部品表
- Fusion 360：枠の最終造形（本人）→ STEPで返して寸法チェック
- Inkscape：プレート・底板の図面確認とレーザーへの出力（本人）
- Blender：完成イメージのレンダリング（任意）

## 進め方
1. 入力をそろえる：KLE JSON（済）、角丸の決定、実測値
2. プレート：図面生成（v01済）→ テストカット（スイッチ穴1＋スタビ1組）→ カーフ確定 → 本番
3. 枠：土台モデル → USB部と角の試し刷り → 2分割で本番
4. 底板：プレートと同じ外形・穴で切断
5. 組み立て：スタビ取付 → スイッチをトッププレートに挿す → PCBに載せてはんだ付け → 台座をボトムプレートに貼る → 補強板・枠・ボトムプレートを重ねて共締め → 動作確認
   ※補強板はスイッチを挿す前にトッププレートの下へ重ねておく（スイッチの下部が補強板の穴を通る）

## 未決事項
- 角丸の半径とスムージング（テスト片を現行iPadの角に当てて決める）
- CO2レーザーの加工エリア（プレート・底板に **315×126mm以上** が必要）
- 補強板の厚さ（2mm／3mm）、ボトムプレートの厚さ
- 補強板の穴の大きさ（爪の逃げ0.8mm、スタビのハウジング下部）→ テストカットに補強板の小片も入れて確認
- 台座の素材（PORON・シリコン・EVAなど）、高さ、配置
- アクリルの種類（キャスト／押し出し）と色・透明度
- ネジの長さと留め方（ナット／熱圧入インサート）。合計の高さは14.6mm（仮）
- 剛性が足りなければ：補強板とトッププレートの間に薄い両面テープ、またはキーの間にM2の小ネジを数本足す
- DZ60実測値（USB-C位置・高さ、裏面部品高さ）→ USB切り欠き位置と枠の厚さが決まる
- 足（旧デザインには3Dプリントの足あり）を付けるか
