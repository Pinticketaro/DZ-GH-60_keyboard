# 基準寸法（GH60互換）

出典：GH60オープンソースPCB（https://github.com/komar007/gh60 の keyboard.kicad_pcb）から抽出。
DZ60はGH60互換のネジ穴配置（KBDfansの60%ケースがGH60標準ネジ穴でDZ60各版に対応と明記）。
**DZ60固有の値（USB-C位置など）は `measurements/dz60_実測.md` で実測して確定させる。**

## キー配置
- 1U = 19.05 mm
- 左上キー（Esc）の中心：(9.1475, 9.19875)
- キー領域15U×5Uは、PCB中心に対して中央配置
- 任意キーの中心 = (−0.375 + (x + w/2)·19.05, −0.325 + (y + h/2)·19.05)　※x, y, w, h はKLEの値（U単位）

## 高さ方向（PCBはネジ止めせず、スイッチの爪と肩でトッププレートに固定）
図：`docs/img/section_v04.png`

| 層（上から） | 厚さ（mm） | 備考 |
|---|---|---|
| トッププレート（アクリル） | 1.5 | 穴14.0。MXの爪がこの板の裏に掛かる（1.6mm以下であること） |
| 補強板（アクリル） | 2.0（仮） | 穴は片側0.8mm大きい（スイッチ15.6角、スタビも同様）。穴と穴の間の最小幅2.7mm。M3で共締め |
| 補強板の下面〜PCB上面 | 1.5 | ＝ 5.0（プレート上面〜PCB上面、MX規格）− 1.5 − 2.0 |
| PCB | 1.6（要実測） | |
| 台座（柔らかい素材） | 5.0（仮） | PCB裏の部品・USB-Cより高く。少しつぶれる分を見込む |
| ボトムプレート（アクリル） | 3.0（仮） | |
| **枠（PLA）** | **8.1** | ＝ 1.5 ＋ 1.6 ＋ 5.0 |
| **合計** | **14.6** | キーキャップ・足を除く。M3ネジは 14.6＋ナット分 |

- 補強板を3mmにすると、補強板とPCBの間は0.5mm、枠は7.1mmになる（`STIFF_T = 3.0`）。
- スタビライザーのワイヤーの通り道は、トッププレート・補強板とも貫通してつながっている（スペース：幅4.6mm＋補強板は片側0.8mm広い）。
- PCBマウントスタビのハウジング下部（PCB近く）が補強板に当たらないか、テストカットで実物確認する。
