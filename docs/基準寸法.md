# 基準寸法（GH60互換）

出典：GH60オープンソースPCB（https://github.com/komar007/gh60 の keyboard.kicad_pcb）から抽出。
DZ60はGH60互換のネジ穴配置（KBDfansの60%ケースがGH60標準ネジ穴でDZ60各版に対応と明記）。
**DZ60固有の値（USB-C位置など）は `measurements/dz60_実測.md` で実測して確定させる。**

## 座標系
- 原点：PCB外形の左上、X右・Y下、単位mm

## PCB
| 項目 | 値 |
|---|---|
| 外形 | 285.0 × 94.6 mm |
| 角R | 2.0 mm |
| 厚さ | 1.6 mm（要実測） |

## ネジ穴
| # | 種類 | X | Y | 穴径 |
|---|---|---|---|---|
| H1 | 丸穴 | 25.20 | 27.90 | φ2.5 |
| H2 | 長穴 | 128.20 | 47.00 | 5.0×2.5 |
| H3 | 長穴 | 190.50 | 85.20 | 5.0×2.5 |
| H4 | 長穴 | 260.05 | 27.90 | 5.0×2.5 |
| S1 | 左端スロット | 1.46 | 56.50 | 7.0×2.5 |
| S2 | 右端スロット | 283.54 | 56.50 | 7.0×2.5 |

M2ネジ前提。ケースのボスはH1〜H4を基本にする。

## キー配置
- 1U = 19.05 mm
- 左上キー（Esc）の中心：(9.1475, 9.19875)
- キー領域15U×5Uは、PCB中心に対して中央配置
- 任意キーの中心 = (−0.375 + (x + w/2)·19.05, −0.325 + (y + h/2)·19.05)　※x, y, w, h はKLEの値（U単位）

## プレート
| 項目 | 値 |
|---|---|
| スイッチ穴 | 14.0 × 14.0 mm（カーフ補正前） |
| 厚さ | 1.5 mm |
| PCB上面〜プレート上面 | 5.0 mm |
| スタビ間隔（2U〜2.75U） | キー中心から ±11.938 mm |
| スタビ間隔（6.25U） | キー中心から ±50.0 mm |

スタビ穴の形状は ai03 Plate Generator（https://kbplate.ai03.com）の出力を基準にする。

## ケース（PLA）
- PCB下クリアランス：3.5 mm以上（要実測）
- PCB・プレートの収まり：片側0.25〜0.3 mm
- 壁厚：2.4 mm以上
- ネジ受け：M2熱圧入インサート、ボス外径6〜7 mm
- 分割位置の候補：X ≈ 155〜160（ネジ穴H2・H3を避ける）
