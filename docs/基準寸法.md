# 基準寸法（GH60互換）

出典：GH60オープンソースPCB（https://github.com/komar007/gh60 の keyboard.kicad_pcb）から抽出。
DZ60はGH60互換のネジ穴配置（KBDfansの60%ケースがGH60標準ネジ穴でDZ60各版に対応と明記）。
**DZ60固有の値（USB-C位置など）は `measurements/dz60_実測.md` で実測して確定させる。**

## 座標系
- 原点：PCB外形の左上、X右・Y下、単位mm

## キー配置
- 1U = 19.05 mm
- 左上キー（Esc）の中心：(9.1475, 9.19875)
- キー領域15U×5Uは、PCB中心に対して中央配置
- 任意キーの中心 = (−0.375 + (x + w/2)·19.05, −0.325 + (y + h/2)·19.05)　※x, y, w, h はKLEの値（U単位）

| 項目 | 値 | 備考 |

| 外形 | 315.0 × 126.0 mm | PCB中心に対して中央。外形の左上 = PCB座標 (−15.0, −15.7) |
| 角 | Apple風の角丸（クロソイド＋円弧） | 仮：R12・スムージング0.6（角から18.1mmでカーブが始まる） |
| 枠の幅 | 14.0 mm | 枠の内側 287 × 98 mm、PCBとのすき間 約1.0 mm |
| 枠の内側の角 | Apple風 R4.5・スムージング0.6 | 角から6.8mmでカーブが始まる。PCBの角（R2）とのすき間0.58mm。これ以上大きくするとPCBに当たる（生成時に自動チェック） |

| M3穴 | φ3.4 × 8 | 中央4本：X = 92.7, 177.0／Y = −8.7, 103.3。角4本：角丸に合わせ、外周と枠の内側から等距離（v02：X = −5.3, 290.3／Y = −6.0, 100.6、穴の縁から外周・内側まで約6.4mm） |

## 高さ方向（PCBはネジ止めせず挟み込み）
図：`docs/img/section_v03.png`

| 層（上から） | 厚さ（mm） | 備考 |
|---|---|---|
| トッププレート（アクリル） | 3.0（仮） | 1.5mm超なのでMXのツメはかからない。スイッチの肩がプレート上面に当たって止まる |
| プレート下面〜PCB上面 | 2.0 | ＝ 5.0（プレート上面〜PCB上面、MX規格）− プレート厚 |
| PCB | 1.6（要実測） | |
| 台座（柔らかい素材） | 5.0（仮） | PCB裏の部品・USB-Cより高く。少しつぶれる分を見込んで、つぶれる前は数値より少し高くする |
| ボトムプレート（アクリル） | 3.0（仮） | |
| **枠（PLA）** | **8.6** | ＝ 2.0 ＋ 1.6 ＋ 5.0 |
| **合計** | **14.6** | キーキャップ・足を除く |

- トッププレートを厚くするほど「プレート下面〜PCB上面」が狭くなる。4mmで1.0mm、5mmで0（不可）。
- スタビライザーのワイヤーの通り道は、プレートの穴が貫通してつながっている（スペース：幅4.6mm）。厚いプレートでも当たりにくいが、テストカットで実物確認する。
