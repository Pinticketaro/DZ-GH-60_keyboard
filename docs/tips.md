# 自作キーボード（DZ60）Tips集

最終更新：2026-10-14
※ 数値は一般的な目安。自分の機材でテストして値を確定させること。

---

## 1. 設計全般

- **座標の原点を1つに決める**：PCB外形の左上を原点（X右・Y下）に統一。Fusion・Inkscape・Claude側の全データを同じ原点で作ると、重ね合わせチェックが一発でできる。
- **寸法は変数（パラメータ）で持つ**：カーフ値、公差、壁厚、USB位置などは数値を直接書かず変数にする。実測やテスト結果で1か所直せば全体が追従する。
- **単位はmmで統一**：Inkscape（px）とBlender（m）は初期設定がmm以外なので、最初に変更しておく。
- **実物合わせは小さく試す**：本番の前に、スイッチ穴1個の板、USB部分だけのケース片など、短時間で済む試作で確認する。

## 2. はんだ付け（DZ60 V2）

- **組み立て順を守る**：①PCB単体で動作確認 → ②スタビ取付 → ③スイッチをプレートに挿してPCBに載せる → ④四隅だけはんだ → 傾き確認 → ⑤残りをはんだ。はんだ後はスタビもプレートも外せない。
- **動作確認はピンセットで**：はんだ前にPCBをPCにつなぎ、スイッチ穴の2つの接点をピンセットでショートさせて全キーの反応を見る（VIAやキーボードテスターサイトで確認）。
- **配列の照合**：DZ60 V2は複数レイアウトに対応している分、使うスイッチ穴の組み合わせを間違えやすい。KLEの配列とPCBのシルク（印刷）を照合してから挿す。
- **こて温度**：無鉛はんだなら330〜350℃前後が目安。1点に3秒以上当て続けない。
- **はんだ吸い取り線を用意**：付け間違いの修正に必須。
- **フラックス**：はんだの流れが良くなり、イモはんだを防げる。

## 3. プレート（CO2レーザー）

- **カーフ補正**：穴は内側へk/2、外形は外側へk/2オフセット。kは機材・素材・出力ごとに違うので、テストで決める。
- **テストピース**：スイッチ穴を「13.9 / 14.0 / 14.1mm」など少しずつ変えて並べた板を切り、スイッチが「パチッとはまって抜けない」ものを採用すると早い。
- **切る順番**：内側の穴を先、外形を最後。外形を先に切ると板がずれて穴位置が狂う。
- **素材の注意**
  - POM：しなりがあり割れにくい。切断時にホルムアルデヒドが出るので換気必須。
  - アクリル：きれいに切れるが1.5mmはスタビ周りが割れやすい。押し出し材より**キャスト材**の方が切り口がきれい。
  - 合板：安く試作向き。焦げ（ヤニ）が出るのでマスキングテープを貼って切ると汚れにくい。
  - **PVC（塩ビ）は絶対に切らない**：塩素ガスが出て機材も体も傷む。素材が不明な板は切らない。
- **ピント合わせ**：板の反りで焦点がずれると切り残しが出る。押さえ治具や重しで平らにする。

## 4. ケース（PLA・Ender-3）

- **造形エリア**：Ender-3系は約220×220mm。60%ケース（幅約290〜300mm）は2分割必須。
- **分割位置**：ネジ穴（X=128.2、X=190.5）を避けて X≈155〜160 あたり。
- **公差**：はめ合いは片側0.25〜0.3mmから試す。穴は小さめに出やすいので、ネジ穴はやや大きめに設計。
- **熱圧入インサート**：はんだごてで押し込む。こての先にインサート専用チップがあると垂直に入れやすい。温度は200〜220℃程度から。
- **壁厚**：ノズル0.4mmなら2.4mm（6周）以上。ネジボスの周りは厚めに。
- **反り対策**：大きく平たい部品は四隅が反りやすい。ブリム、ベッドの清掃、ベッド温度60℃前後。
- **印刷の向き**：底面をベッドに付ける向きが基本。外から見える面が上に来るようにすると仕上がりがきれい。
- **熱に注意**：PLAは約60℃で変形する。夏の車内や直射日光の当たる窓際に置かない。

## 5. Fusion 360

- **ユーザーパラメータを使う**：「修正」→「パラメータを変更」で、公差・壁厚・カーフなどを名前付きで管理。Claudeが渡す数値と名前を合わせると対応がわかりやすい。
- **スケッチは拘束で固める**：寸法・拘束で完全拘束（線が黒）にしておくと、パラメータ変更で崩れない。
- **STEPで受け渡し**：Claudeとのやり取りは STEP（.step）。.f3d は中身を読めない。
- **プレート図面の書き出し**：スケッチを右クリック →「DXF形式で保存」。
- **分割**：「ボディを分割」で分割面を指定。ダボ穴は分割後に両側へ。

## 6. Inkscape

- **単位をmmに**：「ドキュメントのプロパティ」で表示単位とスケールをmmに。
- **線の扱い**：レーザーは線（パス）を切る。塗りではなく線にし、線幅は細く（0.01〜0.1mm）。切断・彫刻を色で分けるのが一般的。
- **オブジェクトをパスに**：四角形や文字は「パス」→「オブジェクトをパスへ」してから書き出すと加工ソフトで崩れにくい。
- **重複線を消す**：同じ場所に線が2本あると2回切られて焦げる。
- **DXF書き出し**：「名前を付けて保存」→ Desktop Cutting Plotter（R14）DXF。単位をmmに設定。

## 7. Blender（任意）

- **単位設定**：シーンプロパティ → 単位 → 長さをミリメートル、単位スケール0.001。
- **STEPは直接読めない**：Fusionから OBJ / STL を書き出して読み込む。
- **書き出し時のスケール確認**：STL書き出しで1000倍・1/1000にならないか毎回確認。

## 8. Git（このリポジトリ）

- **差分が見えるのはテキスト形式**：KLE JSON、SVG、DXF、CadQueryコード、Markdown。座標や寸法の変更が行単位で見える。
- **STL・STEPは版の記録**：中身の比較はできないが、GitHubはSTLをブラウザで3D表示でき、版の違いも重ねて見られる。
- **重くなったら Git LFS**：大きいSTL/STEPが増えてリポジトリが重くなったら導入を検討。
- **コミット＝製作ログ**：「何を変えた → 実物でどうだった → 次に何を試す」を1コミットに。
- **タグで実物と対応付け**：テストカットや印刷をしたら `test-cut-1` などのタグを付ける。

## 9. Claudeの使い方テクニック

### ファイルの受け渡し
- **作業フォルダを接続する**：デスクトップアプリで入力欄の「＋」→「フォルダを追加」。リポジトリのフォルダを接続すれば、Claudeが直接読み書きできる。
- **ファイル名に版番号**：`plate_v03_kerf0.15.dxf` のように、版と主要パラメータを名前に入れる。
- **形式**：Claudeが読めるのは SVG・DXF・STEP・STL・OBJ・画像・PDF。.f3d と .blend は書き出してから渡す。

### 頼み方
- **1回のメッセージにまとめる**：関連する質問や作業は1通にまとめる方が、往復が減って使用量も抑えられる。
- **前提を最初に書く**：「プレートv03、カーフ0.15で切ったらスイッチがゆるい」のように、版・数値・結果をセットで伝える。
- **実物の写真を送る**：はまり具合、反り、はんだの状態は写真が一番伝わる。定規を一緒に写すと寸法の目安になる。
- **数値を測ったら必ず伝える**：実測値は `measurements/` とスキルに反映させ、以後の設計に使う。

### このプロジェクトの活用
- **プロジェクトのドキュメント**：「決定事項」「Tips」のように、何度も参照する情報を置く。新しいチャットでも引き継がれる。
- **スキル**：DZ60の寸法と設計手順をスキルとして保存済み。設計の話をすると自動で参照される。実測値が出たら更新を頼む。
- **チャットは話題ごとに分ける**：「プレート設計」「ケース設計」「はんだ付け」などでチャットを分けると、会話が長くなりすぎず、使用量も抑えられる。
- **過去のチャットを参照させる**：「前のチャットで決めたカーフ値を使って」と頼めば、過去の会話を検索して引き継げる（有料プラン）。

### チェックを頼む
- **重ね合わせチェック**：「PCB・プレート・ケースを重ねた図を出して」と頼むと、穴ずれや干渉を画像で確認できる。
- **部品表**：「この配列で必要なスイッチ・スタビ・ネジの数を表にして」で数え漏れを防ぐ。
- **書き出しデータの検証**：Fusionから返したSTEPを渡して「基準寸法と合っているか確認して」と頼む。
